## 时代背景

1894 年，大清帝国败于一向被视为「东夷小国」的日本，北洋舰队全军覆没。1895 年《马关条约》签订，割让台湾、澎湖列岛，赔款白银二亿两，后因三国干涉还辽又追加三千万两「赎辽费」。这笔赔款相当于清政府三年多的财政收入。

此后列强掀起瓜分中国的狂潮：俄国诱迫签订《中俄密约》将东北划入势力范围；德国借巨野教案强占胶州湾；法国租借广州湾；英国租借威海卫和九龙半岛；日本将福建划入势力范围。

1898 年，爱国华侨谢缵泰绘制《时局图》，以熊、鹰、犬、蛤蟆等动物盘踞中国版图，将瓜分危机形象地呈现在国人面前。

## 核心主题

在「国已不国」的至暗时刻，不同阶层、不同立场的中国人如何面对亡国灭种的现实，以及「醒」与「不醒」之间的艰难抉择。

## 主要人物

**玩家角色**

- **沈怀瑾**（男，22 岁）—— 赴京会试的举子，湖南湘乡人。出身书香门第，师从主张「经世致用」的学者。玩家通过他的视角体验从传统士大夫到维新志士的思想转变。
- **林婉如**（女，20 岁）—— 通商口岸买办家庭的女儿，自幼在上海长大，受过西式教育。故事线聚焦「商战」与民族经济。

**核心 NPC**

- **沈鹤龄**（55 岁）—— 沈怀瑾之父，湘乡乡绅。经历过太平天国动荡，曾寄希望于洋务运动。甲午战败后世界观崩塌，代表「旧一代的幻灭」。
- **严又陵**（严复，历史人物）—— 天津水师学堂总教习。以「物竞天择」的阐释引导玩家理解「为什么中国会挨打」。
- **张季直**（张謇，历史人物）—— 1895 年新科状元，却在巅峰时刻选择辞官办厂。
- **黎景高**（虚构）—— 台湾知府，参与「台湾民主国」抵抗运动。通过他的通信，玩家得以了解台湾割让后的悲剧命运。

## 互动机制

### 一、觉醒度

沈怀瑾、林婉如各自拥有独立的「觉醒度」数值，通过对话选择、事件应对、信息传播方式等积累。觉醒度影响可解锁的叙事线和最终结局。界面右上角实时显示。

### 二、书信系统

游戏中的关键信息以书信形式呈现。玩家可以阅读书信，部分书信允许玩家改写结尾——不同的落笔方式会改变收信人的反应，产生后续回响。

### 三、时局图动态呈现

游戏主界面是一幅逐渐展开的《时局图》。随着剧情推进，代表列强的动物逐一出现，占据版图。点击右上角「时局图」可随时凝视当前局势，查看已发生的历史事件。随解锁数量增加，地图逐渐变暗。

### 四、史实注

每一章附有史实注，逐条列出该章所依据的条约、言论、事件，标明出处，供审读与教学使用。

## 史实依据

剧中关键历史事件、人物言论、条约细节均有史料依据：

- 《马关条约》割让台湾、赔款二亿两白银，加「赎辽费」三千万两
- 三国干涉还辽及俄国趁机将东北划入势力范围
- 德国借巨野教案强占胶州湾，列强掀起租借港湾、划分势力范围的狂潮
- 严复 1895 年发表《救亡决论》、1897 年译成《天演论》
- 公车上书由康有为联络一千三百余名举子发起
- 张謇 1895 年辞官创办大生纱厂
- 台湾民主国成立及乙未抗日的基本史实
- 谢缵泰 1898 年绘制《时局图》及其题诗

**虚构人物声明**：沈怀瑾、沈鹤龄、林婉如、黎景高、黎景明、周子安、陈道台等为虚构人物；严复、康有为、张謇、谭嗣同、丘逢甲、刘永福等为历史人物。虚构人物的经历与对话系创作性重构，用以串联宏大历史与个体体验。

### 已作的两处史实校正

1. **《国闻报》时间线**。原大纲写沈怀瑾「成为《国闻报》匿名撰稿人」。《国闻报》由严复等人创办于光绪二十三年十月（1897 年 10 月），而第一章时间跨度为 1895—1896 年，其时该报尚未问世。剧中改为沈怀瑾向天津《直报》投稿（严复 1895 年正是在《直报》上发表《论世变之亟》《原强》《辟韩》《救亡决论》），并以严复「打算自己办一份报」一语为《国闻报》埋伏笔。

2. **序章题记**。题记引谭嗣同「四万万人齐下泪，天涯何处是神州」，此诗作于丙申（1896 年），晚于序章所写的 1895 年 4 月。剧中将其作为全书题记使用，而非剧中人物当时所读，并在史实注中说明。

## 技术说明

- 单文件 HTML + CSS + 原生 JavaScript，无任何外部依赖
- 存档使用浏览器 `localStorage`
- 键盘操作：`空格` / `回车` 继续，`M` 打开时局图，`L` 打开回想，`Esc` 关闭弹层
- 剧本数据与渲染引擎分离，`SCRIPT.scenes` 为纯数据，便于后续续写与迁移
